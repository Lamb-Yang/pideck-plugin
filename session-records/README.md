# 会话记录管理（PiDeck 宿主插件）

跨项目把会话归入**固定分组**做长期归属标记：分组只在本面板展示，**不影响 PiDeck 侧栏**——侧栏留给官方「会话分组」（临时任务集合），两者可同时启用、互不干扰。

## 与官方「会话分组」的区别

| | 会话记录管理（本插件） | 官方 会话分组 |
| --- | --- | --- |
| 定位 | 长期归属标记（会话属于哪个项目/事项） | 临时任务的多会话集合 |
| 侧栏 | 不展示 | 分组实时同步到侧栏 |
| 归属 | 一个会话只属一个组 | 一个会话可属多个组 |
| 范围 | 全工作区（跨项目同组） | 全工作区 |
| 数据 | 插件私有 storage | 宿主 store |

## 功能

- 工作区范围：加载全部项目的会话（`sessions.read.workspace`），不同项目的会话可放进同一个组
- 行内目录短名：每条会话标题旁显示所属目录末段（悬停看全路径），跨项目一眼区分
- 单栏折叠列表：分组 + 「未分组」区，展开/收起状态自动记住；顶栏「全部展开/全部收起」
- 星标：行内 ★ 一键切换（空星/金色实星），顶栏「只看星标」过滤，可与搜索叠加
- ⓘ 详情悬浮卡片：悬停/键盘聚焦/触屏点按显示（分组/目录/项目/模型/创建/更新/状态/会话 ID），100ms 意图延迟、移开 180ms 收起、滚动即收、微动画
- 快速搜索：按标题实时过滤（保留分组结构），Esc 或 × 清空
- 新建 / 重命名 / 删除分组（删除前确认，组内会话回未分组）；「添加会话」勾选归组，一个会话只属一个组
- 拖拽归组：会话拖到目标分组卡片即归组；点击会话经 workbench.navigate 跳转（跨项目自动切项目打开）
- 活跃绿点（≤10 分钟）、当前会话高亮条、会话删除后自动清理失效引用
- 打开零闪主题引导（theme-boot.js）；文案跟随界面语言（中/英）

## 安装

1. PiDeck → 设置 → PiDeck 插件 → **从文件夹安装…**（或把本目录放进 PiDeck 插件安装目录）
2. **授权并启用**（权限：`sessions.read` + `sessions.read.workspace` + `workbench.navigate`，无网络权限）
3. 侧栏 table 图标即面板入口；与官方「会话分组」共存时各自独立授权

## 开发循环

改文件后：设置 → PiDeck 插件 → **重新扫描** → **授权并启用**（授权绑定整包文件指纹，内容一变就要重新授权）→ 打开面板 → 右键 → 检查。

## 数据

- 全部数据存插件私有 `storage`，单键 `rec.data.v1`（分组 + 折叠状态 + 星标），全局一份不分项目
- v1.x（旧「会话分组」，按项目 `grp.<projectId>` 键）的数据因插件 id 变更不会自动迁移；如需保留旧分组请对照旧面板手动重建
- 会话数据全程只读，不联网、不上传、不写密钥

## 约束自查

- 只用 `window.pideck`（context / sessions / storage / workbench / onEvent），无 fetch、无 Node
- 不写宿主 store（无 `sessionGroups.manage` 权限），分组数据不进 PiDeck 侧栏
- 目录分页用 `nextOffset` 循环拉全；动态文本全部 `textContent`，不用 innerHTML
- 视觉：AntD 形态 + 宿主 `--color-*` token（缺失时本地亮暗兜底）；文案中英双语
