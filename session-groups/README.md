# 会话分组（PiDeck 宿主插件）

把**当前项目**的会话手动整理成分组：有关联的会话放到一起，点一下直接跳过去。

## 功能

- 单栏折叠列表：分组 + 「未分组」区，展开/收起状态自动记住
- 密度三档已移除：固定紧凑单行（绿点 + 标题 + 相对时间；不可读会话带「不可读」中性标签）
- 每条会话行内按钮：★ 星标（点一下切换，空星/金色实星）＋ ⓘ 详情；ⓘ 鼠标悬停/键盘聚焦/触屏点按弹出悬浮卡片，展示完整字段（所属分组/模型/创建时间/更新时间/状态/会话 ID）；100ms 意图延迟防扫过误弹，移入卡片保持显示，移开 180ms、Esc、滚动或重绘自动收起；入场 120ms 微动画（跟随系统减弱动效设置）
- 顶栏「全部展开/全部收起」一键切换：有任一折叠就显示「全部展开」，反之「全部收起」（含未分组区），状态随折叠持久化
- 快速搜索：面板顶部搜索框按标题实时过滤（保留分组结构，命中组自动展开、无命中组隐藏，计数变「n / 总数」），点 × 或 Esc 清空；切项目自动清空
- 星标：每行一键切换（空星/金色实星），存项目数据、删会话自动清理；顶栏「只看星标」过滤，可与搜索叠加
- 新建 / 重命名 / 删除分组（删除前有确认，组内会话回到未分组）
- 「添加会话」弹层：搜索标题 + 勾选，**一个会话只属于一个组**，勾到新组自动从原组移出
- 会话条目：标题 + 模型 + 相对时间；「移出组」按钮；点击经 `workbench.navigate` 在主界面打开
- 拖动归组：整条会话可拖，落到任意分组卡片（含未分组区）即归组，悬停时目标卡片高亮
- 密度三档内容差异化已随密度体系移除，完整信息统一进 ⓘ 悬浮卡片
- 活跃标记：updatedAt ≤ 10 分钟的会话显示绿点（事件驱动 + 每分钟静默重绘）；当前会话以左侧高亮条 + 加粗标题标记
- 当前打开的会话高亮显示
- 打开零闪主题引导：`theme-boot.js` 在首帧前从 sessionStorage 恢复上次主题与宿主配色（首次无记录跟随系统亮暗，外加纯 CSS 兜底），避免暗色兜底先画一帧造成的闪黑
- 会话被删除/归档后自动清理失效引用，改名后标题自动同步（监听 `sessions.changed`）
- 切换项目自动重载该项目的分组；文案跟随界面语言（中/英）

## 安装

1. PiDeck → 设置 → PiDeck 插件 → **从文件夹安装…**
2. 选择本目录（含 `pideck-plugin.json` 的这一层）
3. **授权并启用**（权限只有 `sessions.read` + `workbench.navigate`，无网络权限）
4. 侧栏的 layers 图标即面板入口（工作区内联页）

## 开发循环

改 `app.js` / `styles.css` / `app.html` 后：

设置 → PiDeck 插件 → **重新扫描** → **授权并启用**（授权绑定整包文件指纹，内容一变就要重新授权）→ 打开面板 → 右键 → 检查。

想在普通浏览器里调样式，可在 `app.html` 的 `<script>` 前注入假 `window.pideck`（见开发指南第 8 节）。

## 数据

分组关系存在插件私有 `storage`（每插件 1 MiB），键 `grp.<projectId>`，按项目隔离；只存「组名 + 会话 id 引用」，不存会话内容。会话数据全程只读。

## 约束自查

- 只用 `window.pideck`（context / sessions / storage / workbench / onEvent），无 fetch、无 Node
- 目录分页用 `nextOffset` 循环拉全，不一次超量请求
- 所有动态文本用 `textContent`，不用 innerHTML
- 视觉：AntD v5 形态（组件/圆角/间距/阴影）+ 宿主配色；悬停/焦点浅色用 color-mix 从主题色派生并带逐级回退；操作按钮统一为 14px 线性 SVG 图标（含星标实星/空星两态，不用字符/emoji）；亮色兜底 accent 用深蓝 #0958d9 保证按钮白字对比度
- 主题：优先消费 `--color-*` 宿主 token，但**不依赖宿主的 insertCSS 注入**（webview 导航前插入易丢失）——app.js 把 `context.tokens` 内联到 `<html>` 的 style 上，切主题时随 `context.changed` 刷新；token 缺失时回落到本地亮暗色板（由 `<html data-theme>` 联动）；错误红/遮罩优先消费 `--color-danger`
- 不联网、不上传会话、不写密钥
